# NEXUS Browser V16

- Learning opens one Document Picture-in-Picture window directly from the NEXUS main page (no secondary `window.open` host). Its calculator and AI interface load inside that window.
- On browsers without Document Picture-in-Picture, Learning opens one in-page panel instead.
- Redesigned Learning calculator: glassy dark design, animated entrance, responsive keys, reduced-motion support; unlock with 0003 and =.
- Added Chess.com to Games catalog with cover art, Scramjet launch, Open Directly and Find Another Version search link.
- Preserves AIAPK and existing games, including V13 game-session behavior.

Note: Document Picture-in-Picture support and tab-capture focus vary by browser. Chess.com may restrict proxy access or authentication; the direct link is available. Live behavior requires browser testing.
